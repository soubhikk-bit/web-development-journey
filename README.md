# 🚀 Web Development Journey

> A practical, project-first journey to becoming a modern full-stack web developer.

This repository documents my journey of learning **modern web development by building real projects, solving problems, debugging, and shipping applications**.

I'm using the **Harkirat 0→100 Web Development course** as a learning resource, but my focus is on **understanding concepts and building independently**, rather than simply completing tutorials.

---

## 🎯 Goals

* Learn web development from fundamentals to advanced concepts
* Build projects while learning every technology
* Develop strong problem-solving and debugging skills
* Learn modern frontend development
* Build scalable backend applications
* Understand databases and API architecture
* Build and deploy full-stack applications
* Learn modern development tools and best practices
* Become job-ready as a full-stack web developer

---

## 🧠 Learning Philosophy

I follow a **project-first learning approach**:

```text
Learn
  ↓
Practice
  ↓
Build
  ↓
Break
  ↓
Debug
  ↓
Improve
  ↓
Ship
  ↓
Repeat
```

> **The goal is not to finish tutorials. The goal is to become capable of building things independently.**

# 🐙 Git Workflow

Every project will follow a simple Git workflow:

```bash
# Check changes
git status

# Stage changes
git add .

# Create a commit
git commit -m "feat: describe the change"

# Push to GitHub
git push
```

### Commit Style

I will try to keep commits meaningful:

```text
feat: add responsive navbar
feat: implement task creation
fix: resolve task deletion bug
refactor: improve API structure
style: improve mobile layout
docs: update project README
```
